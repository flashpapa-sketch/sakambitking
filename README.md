# サカムビット公の逆襲

勇者に玉座を奪われた公サカムビットが、6人の仲間と奈落の城デスフォールの地下へ挑む、一人称ダンジョンRPG。ブラウザで遊べます。

- 6人パーティと隊列、職業、AC、回数制の呪文
- 罠つきの宝箱、町の宿屋・寺院・商店
- 全5階（各 19×19）、ミニマップ
- 外部ライブラリなし。`index.html` と `main.js` だけで動作（通常版）
- 立体版（`3d.html`）は 3D 表示と BGM つき

## 遊び方

`index.html`（通常版）か `3d.html`（立体版）をブラウザで開きます。進み具合はブラウザに保存されます。

操作: WASD / 矢印キーで移動、Enter / E で調べる。戦闘中は 1〜5 キー。スマホは画面上のボタン。H キーで操作一覧。

詳しい仕様は [sakambit_design.md](sakambit_design.md) をご覧ください。
